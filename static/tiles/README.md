# Mahjong tile artwork

The SVG tile faces in this directory are copied from the Hong Kong set in
[samoheen/mahjong-tiles](https://github.com/samoheen/mahjong-tiles).

The source repository states that all files are Public Domain / CC0:
https://creativecommons.org/publicdomain/zero/1.0/

Filename mapping:
- m1..m9: characters / 万
- p1..p9: circles / 筒
- s1..s9: bamboos / 条
- east/south/west/north: winds
- red/green/white: dragons

No claim of authorship is made over the original artwork.
